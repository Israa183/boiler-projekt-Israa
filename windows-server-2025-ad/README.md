Windows Server 2025-Activ Directory och behörighetshantering:
Projekt mål: 
Installera Windows Server 2025 i VirtualBox.
Installera och konfigurera Active Directory Domain Services.
Skapa en domänkontrollant (domain Controller)
Skapa och organisera organisatoriska enheter (OU)
Skapa användarkonton.
Skapa globala säkerhetsgrupper.
Organisera användaren efter avdelning.
Skapa centrala företagsmappar.
Konfigurera NTFS-och delningsbehörigheter.
Testa användarnas åtkomst till olika mappar.
Identifiera och felsöka eventuella installations- domän och nätverksproblem.
Projekt beskrivning:
Detta projekten handlar om installation och konfiguration av en Windows Server 2025-miljö för det fiktiva företaget Skämt & Sido Transport AB, projektet genomförs i Oracle VirtualBox
och fokuserar på centraliserad identitets- och behörighetshantaring med hjälp av Active Directory Domain Services (AD DS).
Målet är att skapa en säker och strukturerad IT-infrastruktur där användare och grupper organiseras efter företagets olika avdelningar.
