# boiler-projekt-Israa
Ubuntu linux Samba configuration 
Tekniker och verktyg: Ubuntu Linux, Samba (SMB), systemd, Linux-kommandoraden
Jag använde kommando för att kontrollera Samba-tjänsten: sudo systemctl status smbd --no-pager
Resultat: Terminalutdata visade att: Tjänsten smbd var aktiv och kördes, tjänsten var aktiverad för automatisk start vid systemstart, Samba var redo att ta emot anslutningar.
Färdigheter jag har tränat: kontrollera Linux-tjänster med systemctl, kontrollera tjänsters status, läsa och förstå tjänsteloggar, grundläggande administration av Samba.
